# Baseline Profile for NEXO — AOT-compiled startup paths
# These rules pre-compile critical user-facing screens on first install,
# reducing cold-start JIT overhead.
#
# STATUS: hand-maintained, and CORRECTED. The previous revision was also
# hand-maintained but its descriptors mostly did not resolve, which made the
# whole profile unusable — see "Why the previous list was replaced" below.
#
# Format: <class descriptor>; (AGP class rule — method flags are not supported
# on class-only rules).
#
# Why the previous list was replaced
# ----------------------------------
# Every descriptor here is checked against the built APK, not derived from a
# source file name. The previous revision was written from file names, and file
# names are not class names in Kotlin:
#
#   * A file-level `@Composable fun Foo()` compiles to `FooKt`, so
#     `Lcom/…/LibraryScreen;` does not exist — `…/LibraryScreenKt;` does.
#     That alone accounted for five of the eight dead entries.
#   * `BookGridSection` never existed under any name; the file is
#     `BookGridContent.kt`, so the class is `BookGridContentKt`.
#   * `HomeScreen` lives in `presentation.feature.home`, not
#     `presentation.screen`, so the old descriptor named the wrong package
#     as well as the wrong kind of class.
#
# Why that mattered beyond being untidy: `androidx.benchmark` installs this
# profile through `profileinstaller`'s broadcast before it measures, and a
# profile whose rules do not resolve leaves the receiver with nothing to
# install. It answers `result=0` — "not handled" — and the benchmark aborts
# with `The baseline profile install broadcast was not received`, which reads
# as a missing library and is not one. Nothing measured on the device could
# succeed while this file was wrong.
#
# This is still not a generated profile. It compiles the entry points the four
# benchmark journeys touch, which is what makes `CompilationMode.Partial()`
# meaningful and lets `:app:generateReleaseBaselineProfile` run to produce the
# real one. Replace this file with the artifact that job uploads.
